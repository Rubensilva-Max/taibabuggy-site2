# TaibaBuggyAdventure — site estático

Versão independente em HTML, CSS e JavaScript, preparada para hospedagem estática gratuita.

## Arquivos
- `index.html` — conteúdo e estrutura
- `style.css` — visual responsivo
- `script.js` — menu móvel e ano automático
- `assets/` — imagens recortadas das capturas de tela fornecidas

## Publicar no GitHub Pages usando Android
1. Extraia o ZIP no celular (aplicativo Arquivos/Meus Arquivos).
2. Acesse https://github.com e entre/crie sua conta.
3. Crie um repositório novo, por exemplo `taibabuggy-site`, preferencialmente público.
4. No repositório, use **Add file → Upload files** e envie `index.html`, `style.css`, `script.js` e a pasta `assets` com seus arquivos.
   - Se o celular não permitir enviar a pasta inteira, abra `assets` e envie os quatro JPGs; depois envie os três arquivos principais na raiz do repositório.
5. Abra **Settings → Pages**.
6. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)` e salve.
7. Aguarde alguns minutos. O GitHub mostrará o endereço publicado em Settings → Pages.
